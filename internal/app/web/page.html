About this project

Weather forecasts and temperature and wind alerts for US ZIP codes.

Project reference

R. O. Topaloglu, “Project2 for Cloud Computing Fall 2026,” Marist University, course assignment, 2026, pp. 1–2.

Weather data

Forecast data comes from OpenWeather’s 5 Day / 3 Hour Forecast API. Choose 1–5 days. Available forecasts are spaced three hours apart; each result shows its dates and times.

Alerts and units

Alerts flag high temperature, low temperature, and high wind using the limits shown on the forecast page. Temperature is shown in Fahrenheit and wind in miles per hour.

Hosting

The deployment target is Oracle Cloud Free Tier.
